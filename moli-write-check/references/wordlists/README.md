# wordlists — 合规词库

脚本 `scripts/detect.py` 的确定性检测数据源。**TSV 格式,每行一个词条**:

```
词<TAB>类别<TAB>严重度<TAB>替换建议
```

- `#` 开头的行为注释,解析时忽略
- 严重度三档:`block`(明确违规,必改)/ `risk`(限流或高风险,建议修改)/ `caution`(需结合语境判断)
- 同一个词同时出现在广告法层和平台层时,**平台层条目优先**(更具体)
- 每个文件头部有 `version: YYYY.MM` 注释,改动词库时同步更新

| 文件 | 覆盖范围 | 词条来源 |
|---|---|---|
| `advertising-law.tsv` | 全平台通用,《广告法》绝对化用语等 | 《广告法》第九条 + 市场监管执法案例 |
| `xiaohongshu.tsv` | 小红书笔记(正文/标题/评论) | 《小红书社区公约》及创作者治理规则 |
| `wechat.tsv` | 公众号文章(标题/正文) | 《微信公众平台运营规范》 |
| `douyin.tsv` | 抖音视频标题、口播稿、直播话术 | 《抖音社区自律公约》及电商违规词规则 |

## 维护约定

1. 平台规则更新频繁,词库是**起点而非全集**——脚本命中的只是词面,L3 上下文判断(医疗/金融/软广标注等)由 Agent 完成,见 `instructions/moli-write-check.md`
2. 新增词条必须带严重度和替换建议,便于直接产出合规改写
3. 词条以**公开可查的平台规则与执法案例**为据,不收录纯传闻;拿不准的放 `caution` 档
4. 欢迎通过 issue/PR 补充词条,PR 中请注明依据来源
